Bajo el capó

Aspectos técnicos relevantes

Autenticación

Sesiones PHP server-side. Activación por enlace de correo. Recuperación de contraseña con token de un solo uso. PHPMailer + SMTP.

API REST (MVC)

Validación en 2 capas: frontend y backend. Middleware de autenticación. Rate limiting: 100 req/min/IP.

Cartografía GIS

Leaflet + OpenStreetMap. Geocodificación con Nominatim; fallback a Google Maps cuando Nominatim no resuelve.

Frontend SPA

Capa Api.js centraliza todas las llamadas HTTP. Controladores JS por módulo. Sin framework — JavaScript puro.

Subida de ficheros

Fotos de perfil gestionadas por la API; almacenadas en el servidor con validación de tipo y tamaño en backend.

Seguridad

Credenciales en .env, nunca en código fuente. Aprendido a las malas: incidente GitGuardian resuelto reescribiendo historial.

Notas: ~1.5 min. Aquí el tribunal evalúa tu profundidad técnica. El rate limiting, la validación en 2 capas y el fallback de geocodificación son los más diferenciadores. El incidente de GitGuardian lo puedes mencionar como aprendizaje de gestión de secretos.

Innovación · Línea futura

Propuesta: asistente conversacional

¿Qué es?

Un chatbot integrado en SIGEBO que traduce consultas en lenguaje natural en llamadas a la API REST existente. Con soporte de voz (Web Speech API).

Arquitectura

LLM (Claude / GPT-4o) + tool use sobre los endpoints ya existentes. El modelo respeta los mismos 5 roles del sistema.

  • «¿Quién está de guardia hoy?»
  • «¿Está operativo el camión X?»
  • «Registra emergencia en calle Mayor, 12»
  • «Solicita permiso del 15 al 22 de julio»
